# Reference Material

This directory contains immutable material used to understand and measure RxJS 7.8.2.

- `exports.json` — generated public runtime export manifest for the pinned npm package.
- `rxjs-7.8.2-es3/` — curated files from the verified RxJS 7.8.2 -> ES3/CommonJS downlevel experiment.

Reference code is not implementation code. Do not import it from `src/` and do not refactor it in place.
